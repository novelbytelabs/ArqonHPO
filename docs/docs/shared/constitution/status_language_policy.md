# Arqon Zero Status Language Policy

Version: 0.1.0

## Required Labels

All governance-sensitive outputs must preserve:

- REQUIRES_HUMAN_REVIEW
- development diagnostic only
- NOT SEALED-TEST CERTIFIED
- not promotable

If live constitution loading fails, also include:

- REQUIRES_STALENESS_REVIEW

## Hard Fail

It is a hard fail to remove, soften, contradict, or imply override of required status labels without a human-signed promotion manifest.
