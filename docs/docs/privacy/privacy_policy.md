# Privacy Policy

**Last Updated: May 11, 2026**

This Privacy Policy describes how ArqonHPO ("we," "us," or "our") handles information in relation to the ArqonHPO open-source software and its documentation website.

## 1. Software Usage (Local Execution)

ArqonHPO is designed to run locally on your infrastructure. 

- **No Personal Data Collection**: The ArqonHPO core library and CLI do not collect, store, or transmit personal data to our servers.
- **Local Telemetry & Auditing**: Any telemetry, audit logs, or performance data generated by the software (e.g., through the `AdaptiveEngine` or `Hotpath` modules) is stored locally on your system or sent to endpoints explicitly configured by you (such as a local Prometheus instance).
- **No Phone Home**: The software does not include "phone home" functionality that sends usage statistics or analytics to Novel Byte Labs.

## 2. Documentation Website

Our documentation is hosted on GitHub Pages (https://novelbytelabs.github.io/ArqonHPO).

- **GitHub Privacy Policy**: Because the site is hosted by GitHub, GitHub may collect certain data as described in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement). This typically includes log data such as IP addresses for security and operational purposes.
- **Cookies**: We do not use tracking or advertising cookies on the documentation site. We may use standard browser features to preserve your theme preference (e.g., Light vs. Dark mode).

## 3. External Links

Our documentation may contain links to external sites (e.g., GitHub, Twitter, PyPI). We are not responsible for the privacy practices of those third-party sites.

## 4. Contact

If you have questions about this Privacy Policy or the security of ArqonHPO, please open an issue on our [GitHub repository](https://github.com/novelbytelabs/ArqonHPO).
